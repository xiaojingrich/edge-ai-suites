# Classroom Report Agent (学情Agent)

Generates classroom evaluation reports by analyzing transcription, video analytics, and other classroom data.

## When to Use (Trigger Phrases)

Use this skill when the user asks any of:

- "生成课堂报告" / "Generate a class report"
- "学生参与度怎么样" / "How was student engagement?"
- "课堂总结" / "Summarize the class"
- "出几道测验题" / "Generate quiz questions"
- "分析教学效果" / "Analyze teaching effectiveness"
- "思维导图" / "Generate mindmap"
- Any question about classroom performance, student behavior, or teaching quality

## How to Call

All interactions go through the multi-turn chat endpoint:

```bash
curl -X POST http://localhost:8000/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "<USER_QUESTION>", "output_format": "<FORMAT>"}'
```

Note: `session_id` is optional. If omitted, the system automatically uses the most recent class session.

### output_format Rules

You MUST set `output_format` based on user intent:

- `"report"` — user wants a full structured report (e.g., "生成完整报告", "class evaluation report")
- `"chat"` — user asks a specific question (e.g., "参与度怎么样", "出题", "讲了什么")

### Follow-up Questions

For follow-up questions in the same conversation, include the conversation_id:

```bash
curl -X POST http://localhost:8000/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "<FOLLOW_UP>", "conversation_id": "<CONV_ID>", "output_format": "chat"}'
```

### Single-shot Report (Alternative)

If user explicitly wants just a report with no follow-up:

```bash
curl -X POST http://localhost:8000/generate-report \
  -H "Content-Type: application/json" \
  -d '{"session_id": "<SESSION_ID>", "query": "<USER_QUESTION>"}'
```

## Response Format

The API returns streaming JSON (one line per token):
```json
{"token": "...", "error": "", "conversation_id": "conv_xxx"}
```

Collect all tokens to form the complete markdown response.

## Capabilities

The Report Agent can:
- Generate comprehensive classroom evaluation reports
- Analyze student engagement from video analytics
- Summarize lesson content from transcription
- Generate knowledge mindmaps
- Create quiz questions based on lesson content
- Analyze teacher behavior and movement patterns
- Track trends across multiple sessions (memory system)

## Prerequisites

The session must have at least one of:
- `transcription.txt` — produced during class by ASR
- Video analytics data — produced during class by pose detection
- `summary.md` — can be generated by the agent if transcription exists

## Privacy

All data processing happens locally on the edge device.
Only the user's question text is visible to this skill.
Raw classroom data (transcription, student info, video) NEVER leaves the device.
